## 6. 尚未完成的发布门禁

以下项目需要 API 凭据、外部服务或独立测试环境，本轮没有擅自使用用户密钥或修改本机已安装应用：

1. 真实模型端到端：模型配置、联网对话、AI 续写/改写、工具授权、接受/拒绝修改、网络中断与恢复。
2. 干净系统安装：至少在 Windows 10、Windows 11 各完成一次普通用户安装、首次启动、升级覆盖和卸载残留检查。
3. 代码签名：当前安装包未签名，公开分发时可能触发 Windows SmartScreen 警告。
4. 长时间稳定性：连续编辑和 Agent 运行 4 小时以上的资源占用、崩溃与数据一致性观察。
5. 人工体验验收：按完整测试计划逐项检查快捷键、焦点、窗口尺寸、错误文案、视觉状态和无障碍体验。

## 7. 发布建议

- **内部 RC 发布：可以。** 当前自动化测试、业务数据闭环、生产包与安装包构建均为绿色。
- **公开 V1 正式发布：有条件通过。** 完成第 6 节第 1～3 项且无阻断缺陷后，可更新为正式 Go；长稳与人工体验问题若不影响数据安全，可根据严重级别决定是否随 V1 阻断。
- 任何导致数据丢失、跨项目串数据、未授权工具执行、安装失败或应用无法恢复启动的问题，均应视为 V1 发布阻断项。
